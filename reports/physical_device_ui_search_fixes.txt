1. STUDENT MY ACTIVITY REMOVAL
--------------------------------------------------------------------------------
- Background:
  In earlier iterations, the Student module had a "My Activity" tab displaying
  posted jobs and events. However, Students have view-only access and cannot post
  jobs or events (the Create (+) action was already removed for Students). Therefore,
  "My Activity" was redundant and created a confusing user experience.

- Changes Implemented:
  * Modified `lib/screens/dashboard/student_home_screen.dart`:
    - Reduced DefaultTabController length from 5 to 4.
    - Removed the "My Activity" Tab from TabBar (icons and label).
    - Removed `MyActivityPage` from the TabBarView children.
    - Removed `MyActivityPage` class definition from `student_home_screen.dart`.
    - Removed unused imports (`event_model.dart`, `event_service.dart`, `event_card.dart`).
    - Remaining Student tabs are now cleanly balanced:
      1. Events (calendar icon)
      2. Jobs (work briefcase icon)
      3. Alumni (directory icon)
      4. Faculty (badge/members icon)
  * Student navigation indices in `DefaultTabController` now map 0..3 with zero dead slots
    or out-of-bounds indexing.
  * Preserved full functionality of Student Home, Chat, Profile, Directory browsing,
    Job viewing, and Event viewing.
  * Verified that Alumni, Faculty, and Admin retain their respective "My Activity" /
    management features without alteration.


2. TOP-TAB ALIGNMENT CHANGES
--------------------------------------------------------------------------------
- Problem:
  Upper section tab bars across Student, Alumni, and Faculty dashboards were left-
  aligned and not visually centered on standard device screens when `isScrollable: true`.

- Changes Implemented:
  * Added `tabAlignment: TabAlignment.center` to all scrollable top tab bars:
    - `lib/screens/dashboard/student_home_screen.dart` (4 tabs centered)
    - `lib/screens/dashboard/alumni_home_screen.dart` (5 tabs centered)
    - `lib/screens/dashboard/faculty_home_screen.dart` (5 tabs centered)
  * Verified `AdminHomeScreen`:
    - Uses 4 fixed tabs (`isScrollable: false`), which distributes tabs symmetrically
      across the screen width without clipping or horizontal overflow.
  * Styling Consistency:
    - Selected tab indicators: Amber underline (`indicatorColor: Colors.amber`,
      `indicatorWeight: 3`).
    - Selected label style: White, bold typography (`labelColor: Colors.white`,
      `labelStyle: TextStyle(fontWeight: FontWeight.bold, fontSize: 13)`).
    - Unselected label style: `Colors.white70`.
    - Background: Brand navy (`Color(0xFF1A3A8F)`).
    - Responsive behavior: Works on narrow phone widths, large screens, and with large
      font scaling without text clipping or tab jumping.


3. ALUMNI AND FACULTY PLUS-BUTTON REDESIGN
--------------------------------------------------------------------------------
- Problem:
  The bottom navigation (+) action for Alumni and Faculty previously rendered as a dark/black
  circular FAB that broke the GLS Connect university brand palette.

- Root Cause:
  The previous FAB container in `MainNavigation` used a default or dark accent override
  rather than adopting the official brand blue styling.

- Changes Implemented:
  * Redesigned `buildCreateNavItem` in `lib/screens/navigation/main_navigation.dart`:
    - Shape: Refined rounded-square framed container (`width: 36, height: 36`,
      `borderRadius: BorderRadius.circular(10)`).
    - Color/Theme: Deep university brand navy gradient:
      * Light mode: `LinearGradient` from `Color(0xFF2E5BBA)` to `Color(0xFF1A3A8F)`
      * Dark mode: `LinearGradient` from `Color(0xFF2448AC)` to `Color(0xFF1A3A8F)`
    - Border: Subtle translucent border (`Border.all(color: Colors.white.withValues(alpha: 0.35), width: 1.2)`).
    - Elevation/Shadow: Soft controlled shadow (`boxShadow` with `brandNavy.withValues(alpha: 0.28)`, `blurRadius: 6`, `offset: (0, 2)`).
    - Symbol: Clean, high-contrast white plus icon (`Icons.add`, `color: Colors.white`, `size: 22`).
    - Label: "Create" caption beneath the button in brand navy (`Color(0xFF1A3A8F)` in light mode, `Colors.white70` in dark mode).
    - Debounce Protection: Added `_isOpeningCreate` boolean flag to prevent duplicate
      modal bottom sheet presentations if tapped repeatedly.
    - Role Security: Rendered strictly when `widget.userRole.toUpperCase() != "STUDENT"`.
      The Student module has no Create (+) button in bottom navigation or dashboards.
    - Accessibility: Added semantic labels (`Semantics(label: "Create Post, Job or Event", button: true)`)
      and tooltips.


4. SEARCH IMPROVEMENTS BY MODULE
--------------------------------------------------------------------------------
- Created Reusable Component:
  `lib/widgets/app_search_bar.dart`
  * Left-aligned brand navy search icon (`Icons.search`, `color: Color(0xFF1A3A8F)`).
  * Clear `×` button (`Icons.clear_rounded`) that appears dynamically via `ValueListenableBuilder`
    whenever query text is present.
  * Single tap on clear icon clears controller text, triggers `onClear` callback, and resets results.
  * Standardized height, content padding (`horizontal: 14, vertical: 12`), 12px border radius.
  * Visible focus state: Border highlighted in brand navy (`Color(0xFF1A3A8F)`, width: 1.5).
  * Accessible semantics label and text field role.

- Module-Specific Search Implementations:

  A. Jobs Search (Student & Alumni Modules):
     - Search Field: "Search jobs by title, company or skills..."
     - Multi-Field Matching:
       * `jobTitle`
       * `companyName`
       * `skillsRequired`
       * `jobDescription`
       * `location`
     - Case-insensitive, null-safe, trims leading/trailing whitespace.
     - Preserves LPA salary filtering (`SalaryHelper.matchesFilter`) and expiration filters.
     - Empty State: Displays friendly `Icons.search_off_rounded` with guidance and an action button:
       "Reset Search & Filters" which resets query, location dropdown, salary filter, and past jobs switch.

  B. Events Search (Student & Alumni Modules):
     - Search Field: "Search events by title, department or venue..."
     - Multi-Field Matching:
       * `title`
       * `location`
       * `description`
       * `targetDepartment`
     - Preserves department dropdown filter and past events toggle.
     - Empty State: Displays `Icons.search_off_rounded` with a "Reset Search & Filters" button.

  C. Alumni & Faculty Directories:
     - Search Field: "Search $roleLabel by name, department, role..."
     - Multi-Field Matching:
       * Alumni: `userName`, `companyName`, `designation`, `department`, `degree`, `skills`, `currentCity`.
       * Faculty: `userName`, `department`, `designation`, `qualification`, `specialization`, `skills`.
     - Preserves existing test contracts and finder assertions.
     - Empty State: Informative "No $roleLabel match your search" with a "Clear Search" button.

  D. Admin User Search:
     - Search Field: "Search users by name, email, or department..."
     - Multi-Field Matching:
       * `name`
       * `email`
       * `department`
     - Preserves role filter chips (All, Alumni, Faculty, Students).
     - Empty State: Informative message with a "Reset Search & Filters" button.

  E. Network Config Bug Fix:
     - Root cause discovered: `lib/config/api_config.dart` had an accidental space in
       `"http://192.168.0.23 :8080"` which caused `FormatException: 192.168.0.23%20` and network
       connection drops on physical devices and STOMP WebSocket client reconnect loops.
     - Fixed `baseUrl` to cleanly return `"http://192.168.0.23:8080"` with `.trim()`.
