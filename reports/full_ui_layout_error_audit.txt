3. CONFIRMED LAYOUT DEFECTS & ROOT CAUSE ANALYSIS
--------------------------------------------------------------------------------

[DEFECT-01] (CONFIRMED) Jobs and Events Search Empty State Keyboard Overflow
- Symptom: "BOTTOM OVERFLOWED BY 11 PIXELS" with yellow-and-black hazard stripes.
- Affected Screens: Student Events, Student Jobs, Alumni Events, Alumni Jobs, Faculty Events/Jobs.
- Root Cause: In EventList and JobList, empty search results were returned as:
    Center(
      child: Padding(
        padding: EdgeInsets.all(24.0),
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [Icon(48px), Text(16px), Text(12px), ElevatedButton.icon(Reset Button)],
        ),
      ),
    )
  inside an Expanded flex container. When the software keyboard opened, available
  vertical viewport shrank to ~223 logical pixels. The Column required 234 logical
  pixels (48 icon + 16 spacing + 24 title + 6 spacing + 18 subtitle + 16 spacing + 48 button + 48 padding + 10 margin).
  234px - 223px = exactly 11 pixels overflow.

[DEFECT-02] Filter Modal Bottom Sheets Keyboard & Dimension Overflow
- Symptom: Potential RenderFlex bottom overflow when typing in bottom sheet fields or on short viewports.
- Affected Components: EventList._openFilterSheet, JobList._openFilterSheet.
- Root Cause: showModalBottomSheet had isScrollControlled: false (default), clipping
  contents when the software keyboard was displayed.

[DEFECT-03] JobCard Horizontal Flex Overflow on 320px Narrow Viewports
- Symptom: "A RenderFlex overflowed by 425 pixels on the right".
- Affected Component: JobCard (lib/widgets/job_card.dart).
- Root Cause: In JobCard, the metadata chips inside Wrap were implemented as:
    Row(mainAxisSize: MainAxisSize.min, children: [Icon, SizedBox, Text(job.location)])
  Inside Wrap, a Row receives unbounded width along its horizontal axis. When job.location
  or experience text was lengthy (e.g. multi-city or remote addresses) or rendered at
  1.4x font scaling, the Text did not wrap or truncate, expanding the Row to ~713px
  and overflowing by 425 pixels beyond the card boundaries.

[DEFECT-04] EventCard Metadata Row Potential Overflow
- Symptom: Horizontal overflow on narrow displays when both event date and location strings are lengthy.
- Affected Component: EventCard (lib/widgets/event_card.dart).
- Root Cause: Date string was unconstrained beside location in the metadata Row.

[DEFECT-05] Dashboard AppBar Title Flex Overflow on 320px Viewports
- Symptom: "A RenderFlex overflowed by 112 pixels on the right".
- Affected Screens: StudentHomeScreen, HomeScreen (Alumni), FacultyDashboard.
- Root Cause: AppBar title was defined as:
    Row(children: [Icon(26px), Text("GLS Connect", 20px), Spacer(), Container(RoleBadge)])
  On a 320px wide screen, with notification actions taking 56px and leading taking 16px,
  the title received a max width constraint of ~232px. The rigid Spacer() with flex: 1
  attempted to expand while the children totaled > 232px, triggering an unhandled 112px overflow.

[DEFECT-06] MainNavigation Create Modal Sheet Unsafe Layout
- Symptom: Modal sheet content partially obscured or unscrollable on landscape / small viewports.
- Affected Component: MainNavigation.showCreateOptions.
- Root Cause: Lacked SafeArea and dynamic scroll view constraints.

[DEFECT-07] Chat Error State Flex Overflow
- Symptom: Non-scrollable error state in ChatScreen.
- Affected Component: ChatScreen._buildErrorState.
- Root Cause: Unscrollable Column inside flexible container.

[DEFECT-08] Admin User Management Empty State Misalignment
- Symptom: Uncentered text and potential clipping during narrow viewport rendering.
- Affected Component: AdminHomeScreen Users Page empty search state.
- Root Cause: Missing explicit text alignment and horizontal margin constraints.

4. FILES MODIFIED & FIX IMPLEMENTATION DETAILS
--------------------------------------------------------------------------------

1. lib/screens/dashboard/alumni_home_screen.dart:
   - EventList: Implemented the architectural pattern:
       LayoutBuilder(builder: (context, constraints) => SingleChildScrollView(
         physics: const AlwaysScrollableScrollPhysics(),
         child: ConstrainedBox(
           constraints: BoxConstraints(minHeight: constraints.maxHeight),
           child: Center(child: Padding(padding: 16-24, child: Column(...))),
         ),
       ))
     Applied to snapshot.hasError, events.isEmpty, and filteredEvents.isEmpty states.
   - EventList._openFilterSheet: Added isScrollControlled: true, SafeArea, and SingleChildScrollView.
   - JobList: Applied identical LayoutBuilder + SingleChildScrollView pattern to error, initial empty,
     and filtered search empty states.
   - JobList._openFilterSheet: Added isScrollControlled: true and SafeArea.
   - ProfileList: Wrapped directory empty and error states in LayoutBuilder + SingleChildScrollView.
   - MyActivityPage: Wrapped _buildMyJobsList, _buildMyEventsList, and _buildMyPostsList empty states
     in LayoutBuilder + SingleChildScrollView.
   - HomeScreen AppBar: Replaced rigid Spacer() with Flexible(child: Text("GLS Connect", overflow: TextOverflow.ellipsis)),
     compact role badge padding, and withValues() migration.

2. lib/screens/dashboard/student_home_screen.dart:
   - JobList: Applied LayoutBuilder + SingleChildScrollView + ConstrainedBox pattern across all empty/error states.
   - JobList._openFilterSheet: Added isScrollControlled: true, SafeArea, and SingleChildScrollView.
   - ProfileList: Applied LayoutBuilder + SingleChildScrollView pattern.
   - StudentHomeScreen AppBar: Replaced rigid Spacer() with Flexible(child: Text("GLS Connect", overflow: TextOverflow.ellipsis))
     and compact STUDENT badge.
   - Syntax validation: Verified clean FutureBuilder brackets.

3. lib/screens/dashboard/faculty_home_screen.dart:
   - FacultyDashboard AppBar: Replaced rigid Spacer() with Flexible(child: Text("GLS Connect", overflow: TextOverflow.ellipsis))
     and compact FACULTY badge.

4. lib/widgets/job_card.dart:
   - Wrapped the Wrap metadata container inside a LayoutBuilder.
   - Constrained each metadata chip (salary, location, experience) with:
       ConstrainedBox(
         constraints: BoxConstraints(maxWidth: constraints.maxWidth),
         child: Row(mainAxisSize: MainAxisSize.min, children: [Icon, Flexible(child: Text(..., overflow: TextOverflow.ellipsis))]),
       )
   - Prevents horizontal overflow under any combination of screen width and text scaling.
   - Bottom deadline row wrapped in Expanded with maxLines: 1 and TextOverflow.ellipsis.

5. lib/widgets/event_card.dart:
   - Wrapped DateHelper.formatFriendlyDate in Flexible(child: Text(..., maxLines: 1, overflow: TextOverflow.ellipsis)).
   - Location text wrapped in Expanded(child: Text(..., maxLines: 1, overflow: TextOverflow.ellipsis)).

6. lib/screens/navigation/main_navigation.dart:
   - Wrapped showCreateOptions modal bottom sheet in SafeArea and SingleChildScrollView.
   - Bottom navigation items verified with Expanded to prevent flex overflow.

7. lib/screens/chat/chat_screen.dart:
   - Wrapped _buildErrorState in SingleChildScrollView with AlwaysScrollableScrollPhysics.

8. lib/screens/dashboard/admin_home_screen.dart:
   - Added textAlign: TextAlign.center and symmetric horizontal padding to Users search empty state.

9. test/ui_overflow_and_stability_test.dart (NEW):
   - Comprehensive automated test suite verifying empty states under keyboard insets (290px),
     narrow viewports (320px width), and large text scaling (1.4x).
